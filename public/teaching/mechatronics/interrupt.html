    What this draft models
    Timer1 CTC with OCR1A as TOP, a sticky compare A flag, the interrupt mask and global enable, saving the return PC, interrupt entry, vector jump, ISR work, and RETI. A pending flag is one bit, not an event queue: additional matches while it is already set do not accumulate additional requests.
    The default example uses /8 and OCR1A = 12499: (12499 + 1) × 8 / 16 MHz = 6.25 ms. The interval includes counter value zero. Flag clearing occurs when its interrupt is serviced, not merely because interrupts are enabled.
    This is a guided execution model, not an Arduino compiler or a complete AVR emulator. Main work uses illustrative 4-cycle instructions. Equality pauses preserve partial instruction progress; interrupt acceptance waits for the instruction to finish. Entry is modeled as 4 cycles and the vector JMP as 3 cycles. ISR duration is user-specified and includes any intended compiler save/restore overhead before the separately modeled 4-cycle RETI. Exact SEI timing, live timer-register writes, other interrupt sources, nesting, and SREG/general-register preservation are not simulated. Global-enable changes are teaching controls at phase boundaries.
