Model assumptions

Ideal incremental encoder, uniform motion within each step, perfect edges, no missed interrupts, and no mechanical noise. Clockwise-positive is a chosen convention: 00 → 10 → 11 → 01. ×1 counts one edge per cycle, ×2 counts two, and ×4 counts all four. Home marks one physical shaft position once per revolution and is one A/B state wide. It does not by itself reset the position counter or make the encoder absolute. Counter zero is an assumed known starting position; this draft does not model a homing routine.

Pulse counting uses sampled modular position differences. Pulse duration uses quantized timestamps of decoded edges, with an ideal extended timer internally; the display flags intervals requiring overflow handling for the selected timer width. Reversal can make a single duration interval unrepresentative. Hardware latency, ISR costs, oscillator tolerance, and overflow-service code are outside this draft.
