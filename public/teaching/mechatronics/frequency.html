Model & equations

All cases use H(s) = Y(s)/X(s), angular frequency ω = 2πf, and x(t) = A sin(ωt). The sinusoidal output is A|H(jω)| sin(ωt + arg H). Magnitude in dB is 20 log₁₀|H|. The complex FRF supplies both magnitude and phase; a Bode plot displays these against logarithmic frequency.

The mechanism follows mÿ + cẏ + ky = kx. Its damper connects the mass to ground. A damper between the moving spring end and the mass would give a different numerator. The combined case cascades the ideal motion integrator and this mechanism. It has no position feedback. The feedback extension measures final mass position and uses ż = K(x − y), mÿ + cẏ + ky = kz, with z the spring-end position. Thus H(s) = Kk/(ms³ + cs² + ks + Kk). For positive parameters, the Routh criterion gives stability exactly when K < c/m. At equality, poles lie at ±j√(k/m) and −c/m; resonant excitation grows without bound.

The feedback startup response uses a matrix exponential of the continuous linear system and sinusoidal input. Marginal and unstable cases always display startup, since their formal frequency-domain values do not predict an attracting steady response. Plots stop if amplitude exceeds one million times input amplitude, or shorten the time window to resolve fast oscillations. These are display limits, not physical saturation.

K denotes controller gain, while k denotes spring stiffness. The response ratio is output/input, Y/X. Phase uses the correct quadrant and remains continuous down to −270° for the cascade.

Start from rest means zero initial position, velocity, and integrator state. Sinusoidal component isolates the FRF response. An integrator's initial-condition offset does not decay, so its periodic response is not a unique attracting steady state. Ideal tracking has no dynamic state. The model is linear and continuous in time: saturation, sampling, friction, sensor noise, and actuator limits are excluded. No PID controller is introduced in these cases.
